# 2025-08-04-visual-hyper-shiritori

## 概要
- **作成日**: 2025-08-04
- **目的**: ビジュアル式ハイパーしりとりゲーム - 複数文字の重なりを奪い合うマルチプレイヤー対戦ゲーム
- **使用技術**: HTML5, CSS3, JavaScript (Vanilla)

## 特徴
- 文字がブロックとして視覚的に表示される
- 複数文字の重なりを検出して奪える（例：「さかな」→「かなりや」で「かな」を奪取）
- 2〜4人のマルチプレイヤー対応
- ユラユラ揺れるアニメーションとエフェクト
- プレイヤーごとの獲得文字数表示

## セットアップ
1. リポジトリをクローン: 
   ```bash
   git clone https://github.com/[your-username]/2025-08-04-visual-hyper-shiritori.git
   ```
2. HTMLファイルをブラウザで開く:
   ```bash
   # Windows
   start visual-shiritori-fixed.html
   # Mac
   open visual-shiritori-fixed.html
   # Linux
   xdg-open visual-shiritori-fixed.html
   ```

## ゲームルール
1. プレイヤー数を選択（2〜4人）
2. 最初のプレイヤーが任意の単語を入力
3. 次のプレイヤーは前の単語と重なる部分がある単語を入力
4. 重なった文字は入力したプレイヤーが獲得
5. 順番にプレイして、最も多くの文字を獲得したプレイヤーの勝利
